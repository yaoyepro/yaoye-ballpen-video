# 引导开始创作（start-creating）

用户可能这样说：

```text
加载 yaoye-ballpen-video，引导我开始创作。
```

## 第一条引导（读完本 Skill 后发送；已知道的项删掉）

> 已加载「瑶叶·圆珠笔版」。我会用一支蓝色圆珠笔，在横线笔记本上把你的内容一笔一笔写出来、画出来，做成 30–60 秒的短视频（电脑版 1080p + 手机版）。
>
> **先告诉我内容就能开始（任选一种）：**
> 1. 一个**主题**，比如“和太阳奔跑”——我来写文案；
> 2. 几个**关键词**，比如“雨天、书店、热可可”；
> 3. 你写好的**文案**（我一字不改，只负责分页）；
> 4. 一首**诗**；
> 5. 一篇**文章**（我压缩成 6–12 页要点，事实不改）；
> 6. 一首**歌**（音频 + 歌词）。
>
> **可以晚点再定：** 时长（默认 30–45 秒）、配乐（默认只有笔声；也可以自动作曲、或用你的音乐）、要不要角色出镜（需要图片，我也可以帮你生成）。
>
> 你可以直接回：“主题是……，40 秒，配个温柔的音乐。”

## 之后怎么一步步问

| 顺序 | 问什么 | 用户不回答时的默认 |
|---|---|---|
| 1 | 内容（上面 6 选 1） | 必须有，不能默认 |
| 2 | 时长 | 主题/关键词/文案 30 秒；诗 30–40 秒；文章 45 秒；歌 = 歌长 |
| 3 | 配乐 | `none` + 笔声 |
| 4 | 角色图片 | 不用角色，只用涂鸦（风格 A/B） |
| 5 | 输出位置 | Windows `D:\ballpen\<英文名>`（没有 D 盘用 `%USERPROFILE%\ballpen\<名>`）；mac/Linux `~/ballpen/<名>` |

- 每次最多问 2 个问题；用户已经提供的不重复问。
- 收到内容后，**先给方案再动手**：用一张表列出每页的文字 + 主画涂鸦 + 转场（这就是 script.json 的内容），问“这样可以吗？”。用户同意后按 SKILL.md 第 4 节执行。（这是额外的停止点，避免文案方向错了白做。）
- 无法读取用户的附件/路径时，如实说明，请用户把文件放到你能访问的位置。

## 用户可以直接复制的素材消息

```text
使用 yaoye-ballpen-video，风格 A（文字+涂鸦）。
内容（主题）：和太阳奔跑
时长：30 秒；配乐：自动作曲
输出到：D:\ballpen\sun
```
