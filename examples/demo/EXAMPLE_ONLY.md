# EXAMPLE / TEST FIXTURE ONLY

This folder is a runnable song-mode (style D) demo that contains **no personal material and no character images**:

- `audio/demo_song.mp3` — a 17-second instrumental generated by `make_demo_audio.py` (pure numpy formulas, nothing
  sampled; the output is CC0 / public domain). Re-create it any time: `python make_demo_audio.py lullaby audio/demo_song.mp3`.
- `lyrics.txt` — four placeholder lines written for this demo.
- `timeline.locked.json` — the lyric timing for the demo song, written by hand (the demo has no vocals, so ASR is skipped).
  `project.json` points to it with `"timeline_seed"`; it is copied to `work/timeline.json` on first use.
- `logo/demo_logo.svg` — a generic "DEMO" mark.
- `scenes.js` — doodles only (lamp, window, moon, stars, house). A real lyric MV uses YOUR character images: put PNGs in
  `sprites/`, declare them in project.json and call `spr()` / `drawSprite()` (references/SCENE_API.md).

For a real song: `python bpmv.py init <new_project_dir> --mode song` and supply your own audio, lyrics and character images.
